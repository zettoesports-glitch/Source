# Exports / seleção de GPU

A export table do PE possui quatro nomes:

- `AmdPowerXpressRequestHighPerformance`
- `GetFunctionOffset`
- `GetSharedValue`
- `NvOptimusEnablement`

Os exports AMD/NVIDIA são o padrão conhecido para solicitar GPU de alto desempenho em sistemas híbridos. A evidência textual completa está em `evidence/pe_headers_imports_exports.txt`.
